# 就業WEB 残業ビューア

就業WEB（タイムカード画面 `SW020_Main.aspx`）で、**申請時刻ベース**の残業時間と概算残業手当を表示する Chrome 拡張機能です。

申請時刻だけ入力した場合、就業WEB本体では右側に残業時間が表示されません。この拡張機能が同じルールで計算し、タイムカード表の上にサマリーを表示します。申請時刻が未入力の日は、修正後・打刻の退出時刻を順に参照します。

## 機能

- 申請退出時刻から **法定内残業**・**普通残業** の合計を表示（**合計時間**も表示。20時間超でバッジ表示）
- **営業日数**（土日祝を除いた日数）と、経過営業日数に対する **1日平均残業時間** を表示
- **詳細** ボタンで日別内訳（退出時刻・法内・普通・**合計**）を折りたたみ表示（状態は保存）
- **金額** ボタンで概算残業手当を表示（デフォルト非表示、30秒後に自動で隠れる）
- 拡張アイコンのポップアップから単価・相殺額を設定可能

## インストール

1. Chrome で `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」を ON
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. この `shugyo-overtime-viewer` フォルダを選択

## 使い方

1. 就業WEB のタイムカード画面（`SW020_Main.aspx`）を開く
2. タイムカード表の直上にバナーが表示される

```
残業時間（2024年 8月）  法定内 1:16 / 普通 2:28 / 合計 3:44 / 営業日 5/22日（1日平均 0:45）  [詳細 ▼]  [金額]
```

詳細を開くと、日別に合計時間も表示されます。

```
08/01　退出 20:46（申請）　法内 0:30　普通 2:16　合計 2:46
```

- **詳細 ▼** … 日別の残業内訳を表示/非表示
- **金額** … 概算残業手当を表示（他人に見えないようデフォルト非表示）
- **営業日** … `経過営業日数/当月の営業日数`（土日祝を除く）。経過営業日数は実際の今日の日付を基準に判定
- **1日平均** … 合計残業時間 ÷ 経過営業日数

金額表示例:

```
概算残業手当　合計 ¥9,596　→　実質追加 ¥0
```

## 計算ルール

| 項目 | ルール |
|------|--------|
| 始業 | 9:30（早出はカウントしない） |
| 終業 | 18:00 |
| 昼休み | 1時間（所定内） |
| 18:01〜18:30 | 法定内残業（最大 0:30） |
| 18:31以降 | 普通残業 |
| 使用する時刻 | 退出時刻を **申請 → 修正後 → 打刻** の順で参照（いずれも空なら 0:00） |

### 残業代の計算

```
所定残業手当 = 法定内残業（分）× 単価
普通残業手当 = 普通残業（分）× 単価
残業手当 合計 = 上記の合計
実質追加支給 = max(0, 残業手当合計 − 業務手当調整)
```

デフォルト単価（給与明細から逆算）:

| 区分 | 単価 |
|------|------|
| 所定残業手当 | 44.59 円/分 |
| 普通残業手当 | 41.94 円/分 |
| 業務手当調整 | 45,400 円 |

## 設定

拡張機能アイコンをクリックしてポップアップを開き、単価と相殺額を変更できます。給与改定時に更新してください。

## 対象 URL

`manifest.json` では次の URL パターンにマッチします。

- `http://192.168.33.148/shugyo/*/SW020_Main.aspx*`
- `http://*/shugyo/*/SW020_Main.aspx*`

社内のホスト名が異なる場合は `manifest.json` の `matches` を編集してください。

## 注意事項

- 表示される金額は **概算** です。給与明細と完全に一致しない場合があります
- 金額はプライバシー保護のため、ページ読み込み時・年月変更時は常に非表示です
- 土日・休日出勤の区分は考慮していません（退出申請時刻のみで計算）
- 社内利用向けの個人ツールです
