# Redmine チケット自動入力（Chrome拡張機能）

弁護士JP Redmine の新規チケット作成画面で、よく使う必須項目をワンクリックで入力できる Chrome 拡張機能です。

## できること

### ⚡ 一発入力ボタン
新規チケット作成画面の右上に「⚡ 一発入力」ボタンが表示されます。押すと以下の項目が自動で入力されます。

| 項目 | 入力される値 |
| --- | --- |
| 担当者 | 自分（ログイン中のユーザー） |
| 期日 | 今日から ○日後（初期値：14日後。日数は変更できます） |
| 所属(旧トラッカー) | 設定した所属（初期値：システム） |

### 期日の入力漏れ防止
- 期日が空欄のあいだは「作成」「連続作成」ボタンが押せなくなります。
- ボタンの下に「⚠ 期日が未入力のため作成できません。期日を入力してください。」と表示されます。
- 期日を入力すると、ボタンが押せるようになり、警告文も消えます。

### 一発入力の設定
ツールバーの拡張機能アイコンをクリックすると設定画面が開き、「一発入力」で入る値を変更できます。

- 期日：今日から何日後にするか（0〜365日）
- 所属(旧トラッカー)：ディレクター / デザイナー / システム など

## 対象ページ

`https://redmine.vbest.co.jp/projects/*/issues/new`（各プロジェクトの「新しいチケット」画面）

上記以外のページでは動作しません。

## インストール方法

> Chrome ウェブストアには公開していないため、zip を展開して手動で読み込みます。

1. Google ドライブから zip をダウンロードします。
   - ダウンロード先：https://drive.google.com/drive/folders/XXXXXXXXXXXXXXXXXXXX （※仮URL）
2. ダウンロードした zip を展開します。
   - 展開したフォルダは、インストール後も**削除・移動しないでください**（消すと拡張機能が動かなくなります）。
   - 例：`~/Documents/chrome-extensions/redmine-autofill` のような場所に置いておくのがおすすめです。
3. Chrome のアドレスバーに `chrome://extensions` と入力して開きます。
4. 右上の「**デベロッパー モード**」をオンにします。
5. 左上の「**パッケージ化されていない拡張機能を読み込む**」をクリックします。
6. 手順2で展開したフォルダ（`manifest.json` が入っているフォルダ）を選択します。
7. 一覧に「Redmine チケット自動入力」が表示されれば完了です。
8. （任意）ツールバーのパズルアイコン 🧩 から、この拡張機能のピン 📌 をオンにすると、アイコンが常に表示されて設定画面を開きやすくなります。

## 使い方

1. Redmine の「新しいチケット」画面を開きます。
2. 右上の「⚡ 一発入力」ボタンを押します。
3. 担当者・期日・所属が入力されるので、題名・説明などを入力して「作成」を押します。

### 期日の日数・所属を変える
1. ツールバーの拡張機能アイコンをクリックします。
2. 「今日から [ 14 ] 日後」の数字と、所属(旧トラッカー)を選んで「保存」を押します。
3. 次に「一発入力」を押したときから、新しい設定が反映されます。

> 初めて使うときは、**まず自分の所属を設定してください**（初期値は「システム」です）。

※ 設定は Chrome の同期機能で保存されるため、同じ Google アカウントでログインしている他の PC にも引き継がれます。

## アップデート方法

1. Google ドライブから新しい zip をダウンロードして展開します。
2. 以前のフォルダの中身を、新しいファイルで上書きします（フォルダの場所は変えないでください）。
3. `chrome://extensions` を開き、「Redmine チケット自動入力」の再読み込みボタン（↻）を押します。
4. 開いている Redmine のタブも再読み込みします。

※ 期日の日数・所属の設定は、アップデートしても引き継がれます。

## アンインストール方法

`chrome://extensions` を開き、「Redmine チケット自動入力」の「削除」を押します。削除後は、展開したフォルダも消して構いません。

## うまく動かないとき

| 症状 | 対処 |
| --- | --- |
| 「⚡ 一発入力」ボタンが表示されない | 対象ページ（新しいチケット画面）か確認してください。拡張機能が有効になっているかも `chrome://extensions` で確認してください。 |
| 更新したのに動作が変わらない | 拡張機能の再読み込み（↻）のあとに、**Redmine のタブも再読み込み**してください。 |
| 「一部の項目が見つからず設定できませんでした」と表示される | Redmine 側の画面構成が変わった可能性があります。管理者に連絡してください。 |
| Chrome 起動時に「デベロッパー モードの拡張機能を無効にする」と表示される | 手動で読み込んだ拡張機能では毎回表示されます。「キャンセル」（または × ）を押せばそのまま使えます。 |

## 注意事項

- 社内利用を想定した非公式ツールです。

```
├── manifest.json   # 拡張機能の設定
├── content.js      # チケット作成画面での一発入力・期日チェック
├── popup.html      # 設定画面（期日・所属）
├── popup.js        # 設定画面の処理
├── icons/          # アイコン（16/32/48/128px）
└── README.md       # この説明書
```
