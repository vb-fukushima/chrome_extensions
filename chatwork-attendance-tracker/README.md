# Chatwork Attendance Tracker (Chatwork勤怠トラッカー)

Chatworkの投稿から勤務開始・終了のログを自動で抽出・集計し、月別の勤怠管理や残業時間の算出を効率化する Chrome 拡張機能（Manifest V3）です。

---

## 🚀 主な機能

### 1. Chatworkからの勤怠自動抽出
- Chatworkの対象チャットルーム内のメッセージから「【業務開始】」「【業務終了】」が含まれる自分の投稿をスキャンし、出勤・退勤時刻（HHMM形式）を取得します。
- 対象月（1日0時）までの過去ログを自動上スクロールしてロードします。

### 2. スマート更新（差分取得） & キャッシュ機能
- **取得ボタン**: 既にその月のデータが存在する場合、記録済みの最新日までしかスクロールせず、直近〜最新の差分ログのみを素早く取得・合体（マージ）します。
- **強制取得ボタン**: キャッシュを無視して、月全体の最初（1日）から完全に取得し直します。

### 3. 勤務時間 & 残業時間（所定 / 普通 / 合計）の自動計算
- **勤務時間**: 出勤・退勤の両方の時刻が揃っている場合のみ `09:30-18:00` のような時間帯を表示。
- **残業時間ルール**:
  - 定時: `09:30 〜 18:00`
  - 所定残業: `18:00 〜 18:30`（最大30分）
  - 普通残業: `18:30 〜 22:00`
  - 深夜残業: `22:00` 以降（単価1.5倍）
  - 表示形式: `1:30 (所定0:30/普通1:00)`（22時以降があれば `/深夜0:30` が付く）

### 4. 今月のサマリー（自動集計）
- **営業日数**: `実働日数 / 総営業日数`
  - **日本の祝日（振替休日・国民の休日含む）および土日を完全自動判定**して除外した営業日数を算出。
- **残業時間合計**: 今月の総残業時間。
- **1日平均残業**: 実働1日あたりの平均残業時間（`総残業時間 ÷ 実働日数`）。

### 5. クリップボードコピー & Chatworkジャンプ
- **シングルクリック**:
  - 出勤・退勤セル ➔ `0930`（HHMM形式）でコピー ＆ Chatworkの該当投稿へスクロール＆ハイライト。
  - 勤務時間セル ➔ `09:30-18:00` 形式でコピー。
  - 残業時間セル ➔ `1:30 (所定0:30/普通1:00)`（22時以降があれば `/深夜0:30` が付く） 形式でコピー。

### 6. 手動編集機能（打刻忘れ・修正対応）
- 時間セル（未打刻の `-` 表示含む）を**ダブルクリック**すると、インラインで時刻（例: `09:30` や `0930`）を直接編集・補完できます。
- 手動修正されたセルは淡い黄色（`✎` マーク付き）になり、後から「取得」や「強制取得」を行っても**手動編集したデータが勝手に上書きされない自動保護**を備えています。

## 📊 スプレッドシート連携（他デバイスから閲覧）

取得・手動編集・在宅/休み変更のたびに、Googleスプレッドシートへ自動で書き出せます（Apps Script ウェブアプリ経由）。

1. 新しいスプレッドシートを作成 → `拡張機能 > Apps Script` を開く
2. `gas/Code.gs` の内容を貼り付け
3. `プロジェクトの設定 > スクリプトプロパティ` に `TOKEN` = 任意の合言葉 を追加
4. `デプロイ > 新しいデプロイ > ウェブアプリ`（実行ユーザー: 自分 / アクセス: 全員）→ 発行された `/exec` のURLをコピー
5. 拡張機能のポップアップ「Googleスプレッドシート連携」にURLと合言葉を入力して保存
6. `chrome://extensions` で拡張機能を再読み込み（host_permissions 追加のため）

シートには月ごとのタブ（例: `2026-10`）に日別明細、`サマリー`タブに月別集計が入ります。

### GASの自動デプロイ（任意）

`main` に `gas/` 配下の変更をpushすると、GitHub Actions（`.github/workflows/deploy-attendance-gas.yml`）が clasp で Apps Script を更新します。ウェブアプリのURLは変わりません。

事前準備:
1. https://script.google.com/home/usersettings で「Google Apps Script API」をオンにする
2. `clasp login` を実行（`~/.clasprc.json` ができる）
3. GitHubリポジトリの `Settings > Secrets and variables > Actions` に登録
   - `CLASPRC_JSON`: `~/.clasprc.json` の中身
   - `GAS_SCRIPT_ID`: Apps Script の `プロジェクトの設定 > スクリプトID`
   - `GAS_DEPLOYMENT_ID`: `デプロイ > デプロイを管理` にあるウェブアプリのデプロイID


## 🔧 使い方・インストール手順

1. **拡張機能の読み込み**
   - Google Chromeを開き、アドレスバーに `chrome://extensions/` を入力して開きます。
   - 右上の **「デベロッパーモード」** をオンにします。
   - **「パッケージ化されていない拡張機能を読み込む」** をクリックし、本プロジェクトのフォルダを選択します。

2. **初期設定**
   - 拡張機能アイコンをクリックしてポップアップを開きます。
   - 「ChatworkユーザーID」を入力して **「保存」** ボタンを押します（Chatworkのコンソールで `window.MYID` を実行すると確認できます）。

3. **勤怠データの取得**
   - 年・月を選択して **「取得」** ボタンを押します。
   - Chatworkタブが自動で読み込まれ、出退勤時刻と残業時間の集計結果が一覧表示されます。
