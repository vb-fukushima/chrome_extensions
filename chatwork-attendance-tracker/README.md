# Chatwork Attendance Tracker (Chatwork勤怠トラッカー)

Chatworkの投稿から勤務開始・終了のログを自動で抽出・集計し、月別の勤怠管理や残業時間の算出を効率化する Chrome 拡張機能（Manifest V3）です。

---

## 🚀 主な機能

### 1. Chatworkからの勤怠自動抽出
- Chatworkの対象チャットルーム内のメッセージから「【業務開始】」「【業務終了】」が含まれる自分の投稿をスキャンし、出勤・退勤時刻（HHMM形式）を取得します。
- 対象月（1日0時）までの過去ログを自動上スクロールしてロードします。

### 2. スマート更新（差分取得） & キャッシュ機能
- **取得ボタン**: 既にその月のデータが存在する場合、記録済みの最新日までしかスクロールせず、直近〜最新の差分ログのみを素早く取得・合体（マージ）します。
- **強制取得ボタン**: キャッシュを無視して、月全体の最初（1日）から完全に取得し直します。

### 3. 勤務時間 & 残業時間（所定 / 普通 / 合計）の自動計算
- **勤務時間**: 出勤・退勤の両方の時刻が揃っている場合のみ `09:30-18:00` のような時間帯を表示。
- **残業時間ルール**:
  - 定時: `09:30 〜 18:00`
  - 所定残業: `18:00 〜 18:30`（最大30分）
  - 普通残業: `18:30` 以降
  - 表示形式: `1:30 (所定0:30/普通1:00)`

### 4. 今月のサマリー（自動集計）
- **営業日数**: `実働日数 / 総営業日数`
  - **日本の祝日（振替休日・国民の休日含む）および土日を完全自動判定**して除外した営業日数を算出。
- **残業時間合計**: 今月の総残業時間。
- **1日平均残業**: 実働1日あたりの平均残業時間（`総残業時間 ÷ 実働日数`）。

### 5. クリップボードコピー & Chatworkジャンプ
- **シングルクリック**:
  - 出勤・退勤セル ➔ `0930`（HHMM形式）でコピー ＆ Chatworkの該当投稿へスクロール＆ハイライト。
  - 勤務時間セル ➔ `09:30-18:00` 形式でコピー。
  - 残業時間セル ➔ `1:30 (所定0:30/普通1:00)` 形式でコピー。

### 6. 手動編集機能（打刻忘れ・修正対応）
- 時間セル（未打刻の `-` 表示含む）を**ダブルクリック**すると、インラインで時刻（例: `09:30` や `0930`）を直接編集・補完できます。
- 手動修正されたセルは淡い黄色（`✎` マーク付き）になり、後から「取得」や「強制取得」を行っても**手動編集したデータが勝手に上書きされない自動保護**を備えています。

## 🔧 使い方・インストール手順

1. **拡張機能の読み込み**
   - Google Chromeを開き、アドレスバーに `chrome://extensions/` を入力して開きます。
   - 右上の **「デベロッパーモード」** をオンにします。
   - **「パッケージ化されていない拡張機能を読み込む」** をクリックし、本プロジェクトのフォルダを選択します。

2. **初期設定**
   - 拡張機能アイコンをクリックしてポップアップを開きます。
   - 「ChatworkユーザーID」を入力して **「保存」** ボタンを押します（Chatworkのコンソールで `window.MYID` を実行すると確認できます）。

3. **勤怠データの取得**
   - 年・月を選択して **「取得」** ボタンを押します。
   - Chatworkタブが自動で読み込まれ、出退勤時刻と残業時間の集計結果が一覧表示されます。
